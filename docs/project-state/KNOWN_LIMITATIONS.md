# 已知限制（KNOWN_LIMITATIONS）

> 如实记录当前能力边界。每项限制均不得被绕过式实现伪装。

## 1. LLM 客户端尚未接入

- 模型路由为 `deterministic_fallback`，`llm_called: false`
- 语义环节（新颖性候选评分、影响路径识别、语义聚类辅助、预期差判断）全部由确定性规则近似
- V4 Pro 升级机制已定义未启用
- **影响**：评分理由为规则证据，不构成模型推理；语义层面的误判率高于模型方案

## 2. 当前所谓"事件相似聚类"主要由规则实现

- 实现 = 实体+日期预分桶 + 标题相似度（SequenceMatcher）+ 确定性规则
- 无向量相似度、无 LLM 语义判断
- 复杂语义等价（不同措辞的同一事件）可能漏合并；相似标题的不同事件可能误合并
- 文档与报告已改称"事件相似聚类（确定性第一版）"

## 3. 预期差评分仍是规则近似

- 依据关键词（首次/修正/超预期/上调/下调）与保守默认值，非真实市场共识建模
- 任务 13.6 允许的"同类内容传播度/高影响来源讨论度"等信号未接入
- 证据不足时自动降维（保守），不臆测市场预期

## 4. 隔夜市场结构化行情缺失

- 无经过验证的全球市场历史数据源
- 晨报"七、隔夜外围总结"固定降级文案，不提供指数涨跌数字
- 禁止用搜索摘要或模型记忆补数字

## 5. 历史日线只能人工导入

- `market_daily_ohlcv` 无自动来源（primary/secondary 为空）
- fallback=manual_import；日线数据不足时相关分析模块降级或不可用
- sina_quote 仅实时快照，不得冒充日线

## 6. 深度媒体、社区、机构动向主要依赖人工 Inbox

- deep_financial_media / community_sentiment / institutional_activity
  三个方向状态为 manual_only（当前仅支持 manual_inbox）
- 尚无合规自动采集器（社区平台绕登录采集被明确禁止）
- IMA 为 client_only，未自动化

## 7. 尚未开发异动分析

- Phase 3 异动分析未开始（见 NEXT_PHASE.md）
- 个股研报、晚报/复盘、主题挖掘、首次覆盖、自动产业图谱入库均未开发

## 8. 环境与部署限制

- Windows 中文路径 + GBK locale：必须普通 pip 安装（非 editable），代码变更后需重装
- hatch 打包遵循 .gitignore：忽略规则须根锚定（如 `/reports/`），否则误伤 src 内同名包
- 默认测试完全离线；在线验证需显式 `--live` / `probe-sources`，不进入普通 CI
